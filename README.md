Репозиторий содержит материалы курсовой работы по дисциплине **«Машинное обучение в семантическом и сетевом анализе»**. 

В данном проекте реализован полный цикл (pipeline) разработки рекомендательной системы для научных статей: от очистки сырых текстов и топологического анализа графов до обучения глубоких нейронных сетей (Representation Learning) и автоматического A/B-тестирования.

## Цели и задачи проекта
Основная цель — разработка системы контентной фильтрации научных публикаций, превосходящей классические лексические алгоритмы поиска (BM25).
Поскольку прямое обучение рекомендательной системы затруднительно, применяется **прокси-задача (proxy task)** — классификация статей по предметным областям arXiv. Внутренние состояния обученной сети (эмбеддинги) используются для формирования итоговой выдачи алгоритмом $k$-ближайших соседей (kNN).

## Технологический стек
* **Машинное обучение и NLP:** `PyTorch`, `scikit-learn`, `nltk`, `rank_bm25`
* **Сетевой анализ:** `NetworkX` (Louvain Community Detection, Eigenvector Centrality, Quotient Graphs)
* **Оптимизация:** `Optuna` (Байесовская оптимизация гиперпараметров)
* **Визуализация:** `matplotlib`, `seaborn`, `wordcloud`
* **Эмбеддинги:** Предобученные векторы `GloVe 6B (100d)`

## Набор данных
В работе используется подвыборка корпуса [arXiv Dataset (Kaggle)](https://www.kaggle.com/datasets/Cornell-University/arxiv), ограниченная областью компьютерных наук (Computer Science, префикс `cs.`). 
Для работы нейросетевых моделей требуется файл с предобученными векторами [GloVe](https://nlp.stanford.edu/projects/glove/) (`glove.6B.100d.txt`).

## Архитектура проекта
Проект разделен на три логических этапа:

1. **Сетевой анализ и EDA (Unsupervised Learning):**
   * Очистка данных, лемматизация, удаление стоп-слов.
   * Векторизация `TF-IDF` и анализ метрик сети (плотность, распределение степеней).
   * Построение kNN-графа статей и выделение семантических сообществ (Community Detection). Оценка качества кластеризации метриками `NMI` и `ARI`.

2. **Обучение нейронных сетей (Deep Learning):**
   * Проектирование 4-х архитектур: **Deep Text MLP, TextCNN, TextTransformer, TextGRU**.
   * Решение проблемы затухания градиентов методом *Transfer Learning* (инициализация матрицей GloVe).
   * Борьба с переобучением: `Label Smoothing`, `Early Stopping`, `Weight Decay`.

3. **Оптимизация и тестирование (Evaluation):**
   * Автоматический подбор гиперпараметров лучшей модели (TextGRU) с помощью `Optuna`.
   * Симуляция рекомендательной системы: тестирование базовой модели (BM25) и семантической модели (Neural kNN) на независимой выборке запросов.

## Ключевые результаты
Оптимизированная модель **TextGRU** уверенно преодолела заявленный State-of-the-Art бенчмарк для базовых моделей на arXiv, достигнув метрики **F1-weighted = 0.77**.

**Глобальное сравнение рекомендательных систем (Precision@5):**
| Модель | Подход | Average Precision@5 |
| :--- | :--- | :--- |
| **Okapi BM25** | Лексический поиск (Baseline) | ~ 0.68 |
| **Neural kNN** | Семантический поиск (TextGRU) | ~ 0.94 |

Нейросетевая модель успешно перевела тексты в математическое пространство смыслов, выявив скрытые контекстуальные связи, недоступные статистическим методам поиска.
